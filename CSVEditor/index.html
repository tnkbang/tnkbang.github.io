🚀 Tính Năng Chi Tiết

Thao Tác File

Các tính năng:

  • Tạo file CSV mới với kích thước tùy chỉnh
  • Mở file với tự động phát hiện mã hóa (UTF-8, Shift-JIS, v.v.)
  • Mở file trực tiếp từ URL (HTTP/HTTPS)
  • Danh sách file gần đây (Ctrl+1-9 để truy cập nhanh)
  • Hỗ trợ nhiều định dạng: CSV, TSV, và dấu phân cách tùy chỉnh
  • Xuất ra Excel (.xlsx) với độ rộng cột tối ưu
  • Gộp nhiều file CSV thành một với căn chỉnh cột tự động
  • Mã hóa file với bảo vệ mật khẩu
  • Kéo và thả file để mở nhanh
  • Phát hiện thay đổi file từ bên ngoài và tự động nhắc tải lại

Thao Tác Dữ Liệu

Tìm và Thay Thế:

  • Tìm kiếm chính xác, chứa, bắt đầu với, hoặc kết thúc với
  • Tìm kiếm bằng Regex (biểu thức chính quy)
  • Tìm kiếm kiểu SQL (VD: column1 = 'value' AND column2 > 10)
  • Tìm chỉ trong cột hiện tại
  • Đánh dấu tất cả kết quả
  • Thay thế một hoặc tất cả
  • Tìm kiếm song song nhanh cho dữ liệu lớn

Lọc và Sắp Xếp:

  • Lọc cột kiểu Excel với chọn nhiều
  • Tìm kiếm trong giá trị lọc
  • Sắp xếp tăng dần, giảm dần, tự nhiên, hoặc ngẫu nhiên
  • Kết hợp bộ lọc trên nhiều cột

Kiểm Tra Dữ Liệu:

  • Phát hiện dấu ngoặc kép không cân bằng
  • Phát hiện xuống dòng và dấu phân cách trong ô chưa được quote
  • Phát hiện số có số 0 ở đầu, khoảng trắng thừa
  • Bảng lỗi hiển thị theo thời gian thực với sửa nhanh

Thao Tác Hàng & Cột

Các tính năng:

  • Chèn/Xóa hàng và cột ở bất kỳ vị trí nào
  • Ẩn/Hiện hàng và cột với undo/redo
  • Đóng băng hàng và cột để cuộn dễ dàng
  • Tự động điều chỉnh độ rộng cột theo nội dung
  • Căn chỉnh cột: Trái, Giữa, Phải
  • 4 kiểu tiêu đề cột: Số, Excel (A, B, C...), CSV Header, hoặc Tùy chỉnh
  • Chọn nhiều hàng/cột với Shift và Ctrl
  • Đánh dấu ô quan trọng với màu nền (Highlight)

Cài Đặt & Tùy Chỉnh

Các tùy chọn:

  • Thu phóng từ 50% đến 500% (bước nhảy 25%)
  • Chọn mã hóa: UTF-8, Shift-JIS, v.v.
  • Dấu phân cách: Phẩy, Tab, Chấm phẩy, Gạch đứng, hoặc tùy chỉnh
  • Đa ngôn ngữ: Tiếng Việt, Tiếng Anh, Tiếng Nhật
  • Tùy chỉnh màu sắc theo kiểu dữ liệu (Số, Văn bản, Ngày)
  • Tùy chỉnh màu nền, màu chữ, lưới, vùng đóng băng
  • Thêm/Xóa dấu ngoặc kép
  • Tự động kiểm tra cập nhật khi khởi động

🚀 Detailed Features

File Operations

Features:

  • Create new CSV files with custom dimensions
  • Open files with automatic encoding detection (UTF-8, Shift-JIS, etc.)
  • Open files directly from URL (HTTP/HTTPS)
  • Recent files list (Ctrl+1-9 for quick access)
  • Support for multiple formats: CSV, TSV, and custom delimiters
  • Export to Excel (.xlsx) with optimal column widths
  • Merge multiple CSV files with automatic column alignment
  • File encryption with password protection
  • Drag and drop files to open quickly
  • External file change detection with auto-reload prompt

Data Operations

Find and Replace:

  • Search modes: exact, contains, starts with, or ends with
  • Regex search (regular expressions)
  • SQL-like search (e.g., column1 = 'value' AND column2 > 10)
  • Find only in current column
  • Highlight all matches
  • Replace single or all occurrences
  • Fast parallel search for large datasets

Filter and Sort:

  • Excel-like column filtering with multi-select
  • Search within filter values
  • Sort ascending, descending, natural, or shuffle
  • Combine filters on multiple columns

Data Validation:

  • Detect unbalanced quotes
  • Detect unquoted newlines and delimiters
  • Detect leading zeros and trailing spaces
  • Real-time error panel with quick fixes

Row & Column Operations

Features:

  • Insert/Delete rows and columns at any position
  • Hide/Unhide rows and columns with undo/redo
  • Freeze rows and columns for easy scrolling
  • Auto-resize column widths to fit content
  • Column alignment: Left, Center, Right
  • 4 column header styles: Number, Excel (A, B, C...), CSV Header, or Customize
  • Select multiple rows/columns with Shift and Ctrl
  • Highlight important cells with background color

Settings & Customization

Options:

  • Zoom from 50% to 500% (25% increments)
  • Choose encoding: UTF-8, Shift-JIS, etc.
  • Delimiters: Comma, Tab, Semicolon, Pipe, or custom
  • Multi-language: Vietnamese, English, Japanese
  • Customize colors by data type (Number, Text, Date)
  • Customize background, text, grid, and frozen area colors
  • Add/Remove quote marks
  • Auto-check for updates on startup

🚀 詳細機能

ファイル操作

機能:

  • カスタムサイズの新しいCSVファイルを作成
  • 自動エンコーディング検出でファイルを開く（UTF-8、Shift-JISなど）
  • URLから直接ファイルを開く（HTTP/HTTPS）
  • 最近開いたファイルリスト（Ctrl+1-9でクイックアクセス）
  • 複数形式のサポート：CSV、TSV、カスタム区切り文字
  • 最適な列幅でExcel（.xlsx）にエクスポート
  • 自動列配置で複数のCSVファイルを結合
  • パスワード保護付きファイル暗号化
  • ドラッグ＆ドロップでファイルを素早く開く
  • 外部ファイル変更検出と自動再読み込みプロンプト

データ操作

検索と置換:

  • 検索モード：完全一致、部分一致、先頭一致、末尾一致
  • Regex検索（正規表現）
  • SQLライク検索（例：column1 = 'value' AND column2 > 10）
  • 現在の列のみで検索
  • すべての一致をハイライト
  • 単一またはすべての出現を置換
  • 大規模なデータセットの高速並列検索

フィルタとソート:

  • 複数選択可能なExcelライクな列フィルタリング
  • フィルタ値内の検索
  • 昇順、降順、自然順、またはシャッフルでソート
  • 複数の列にフィルタを組み合わせ

データ検証:

  • アンバランスお重覆引用符を検出
  • クォートされていない改行と区切り文字を検出
  • 先頭ゼロと末尾スペースを検出
  • クイックフィックス付きリアルタイムエラーパネル

行と列の操作

機能:

  • 任意の位置で行と列を挿入/削除
  • 元に戻す/やり直し機能付きで行と列を非表示/再表示
  • スクロールを簡単にするために行と列を固定
  • 内容に合わせて列幅を自動リサイズ
  • 列の配置：左、中央、右
  • 4つの列ヘッダースタイル：番号、Excel（A、B、C...）、CSVヘッダー、またはカスタマイズ
  • ShiftとCtrlで複数の行/列を選択
  • 背景色で重要なセルをハイライト

設定とカスタマイズ

オプション:

  • 50%から500%までのズーム（25%刻み）
  • エンコーディングの選択：UTF-8、Shift-JISなど
  • 区切り文字：カンマ、タブ、セミコロン、パイプ、またはカスタム
  • 多言語：ベトナム語、英語、日本語
  • データタイプ別の色カスタマイズ（数値、テキスト、日付）
  • 背景、テキスト、グリッド、固定エリアの色カスタマイズ
  • 引用符の追加/削除
  • 起動時に更新を自動チェック
